Answers

❓ FAQs

How can I add my own handwriting?

Check out the guide to add your own handwriting above.

Where can I get more fonts?

You can find more handwriting-style fonts at quantumenterprises.co.uk/handwriting-fonts.

There are gaps between letters in custom fonts

This is a known issue we haven’t found a fix for yet. As a workaround, use the letter spacing and word spacing options to adjust the gap.

Where can I request features or report bugs?

You can’t. This is a read-only project and there won’t be further improvements.
